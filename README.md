# Spark AI

Spark AI is an AI learning companion designed for students who feel uncertain about the future.  
It provides emotional support, value guidance, and practical advice to help young people build confidence, strengthen beliefs, and move forward with hope and purpose.

## ✨ Features

- AI-based learning companion
- Emotional support for students
- Guidance on values and personal growth
- Practical advice for future planning
- Simple web-based interface
